## Status

Only Phase 00 is implemented: a small Node/Express health API, Docker Compose, segmented `front_net` and `back_net` networks, a diagram, and a runbook. The repository's later UI, database, cache, messaging, worker, FTP, iSeries, observability, resilience, and security phases are planned learning exercises.

Treat this repository as an incremental architecture-learning lab, not a microservices platform or production infrastructure reference.
