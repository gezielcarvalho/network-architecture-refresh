# Project charter

## Purpose

Build a hands-on, phase-by-phase refresher for architectural diagramming and container-based system composition, beginning with a minimal API and network segmentation.

## Portfolio value

The repository shows deliberate architecture communication: diagram-first thinking, network boundaries, Compose usage, a small executable seed, and incremental runbooks. It is best presented as a learning lab rather than a complete product.

## Implemented scope

- Phase 00 minimal Express API with a health endpoint.
- Docker Compose configuration with separate front and back networks.
- Lucidchart export and step-by-step/runbook documentation.

## Planned, not implemented

- UI, database, cache, queue, workers, FTP, legacy adapter, observability, resilience, and gateway layers.
- A real business domain, production deployment, security implementation, CI, or operational support model.
